---
name: brain-sync
description: Push, pull, sync, inspect, restore or transfer the Mavis brain between devices. Use for push my brain, pull my brain, sync brain, brain sync status, brain history, connect another laptop, and brain recovery. Uses the owner-configured encrypted Cloudflare service through the portable local CLI.
---

Run the shipped CLI from the active Mavis code checkout. Resolve private data from the installed activation's brain root or the shared root resolver; never substitute the current project's folder. No Claude, Codex or other model API key is needed.

1. Run `node "<codeRoot>/scripts/brain.mjs" status --brain-root "<brainRoot>" --json`. A configuration error means onboarding is incomplete: read `<codeRoot>/docs/brain-sync/README.md`. Do not create an identity or cloud account to conceal a missing restored brain.
2. Map the user's request exactly: “push my brain” → `push`; “pull my brain” → `pull`; “sync my brain” → `sync`; “brain status” → `status --remote`; “brain history” → `history`. Read-only status is free. An explicit request authorizes its corresponding operation; do not ask repeatedly. `push` and `sync` upload only the reviewed allowlist, including referenced supported images/PDFs. Preview the initial seed with `push --dry-run` and obtain approval for that concrete first scope.
3. Execute `node "<codeRoot>/scripts/brain.mjs" <operation> --brain-root "<brainRoot>" --json`. Inspect the exit code and receipts. Exit 3 means conflict/stale head: show affected paths from a dry-run or protected conflict plan; let the user select local/remote for each path before resolving. Never force a stale push. Exit 4 means offline/timeout: local work remains pending. Exit 5 means credentials/revocation: privately re-enroll. Exit 6 means version incompatibility. Exit 7 requires corruption/interruption recovery. Exit 8 means limits/quota. Report only verified outcomes.
4. For recover/restore/import/revoke/key-rotation requests, read the guide and inspect the concrete preview first. Restore creates a new revision; it does not rewind history. Device revocation cannot erase copied memory. Keys, bearer tokens, invitation unlock secrets and Cloudflare credentials never enter chat, process arguments, logs, Git or the brain. Human private prompts must run in a terminal the owner controls; an unattended agent cannot answer them.
5. A configured sync save uses `save begin` before the paired memory writes, then the code-root linter against `--brain-root`, then `save finish`. Failed or interrupted saves leave the marker for inspection. Save completion never uploads: remind the user that changes are pending only when useful. Avoid recording routine sync receipts in synced memory, which creates endless new changes.

Deployment is a distinct request: `cloud setup` currently produces a resource preview; read `<codeRoot>/docs/brain-sync/cloudflare.md` before provider mutations. Each cloner owns their resources and recovery material. No original-author endpoint or credential is built in.
